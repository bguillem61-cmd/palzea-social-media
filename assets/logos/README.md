# Logos de Palzea

Todos los archivos son PNG con fondo transparente. El símbolo es un anillo en espiral con degradado morado (aprox. #C45BFF a transparente).

## Logos con texto "PALZEA"

| Archivo | Disposición | Color del texto | Usar sobre |
|---|---|---|---|
| `logo-vertical-texto-negro.png` | Símbolo arriba, texto debajo | Negro | Fondos claros |
| `logo-vertical-texto-blanco.png` | Símbolo arriba, texto debajo | Blanco | Fondos oscuros |
| `logo-horizontal-texto-negro.png` | Símbolo a la izquierda, texto a la derecha | Negro | Fondos claros |
| `logo-horizontal-texto-blanco.png` | Símbolo a la izquierda, texto a la derecha | Blanco | Fondos oscuros |

Los PNG de texto blanco parecen mostrar solo el símbolo si se abren sobre fondo blanco: el texto está, pero es blanco sobre transparente.

## Símbolo e icono

| Archivo | Descripción | Usar para |
|---|---|---|
| `logo-simbolo.png` | Solo el símbolo, fondo transparente | Marca de agua, avatares sobre fondo claro, composiciones |
| `icono-app-oscuro.png` | Símbolo dentro de un cuadrado redondeado oscuro (#222328 aprox.) | Foto de perfil de redes sociales, icono de app |
| `icono-app-claro.png` | Símbolo dentro de un cuadrado redondeado muy claro | Variante clara del icono |

## Normas de uso

- No deformar, girar ni cambiar los colores del símbolo.
- Sobre fondo oscuro usar siempre las variantes de texto blanco o el icono oscuro.
- Sobre fondo claro usar las variantes de texto negro o el símbolo solo.
